# java-lotto-precourse

## 🚀 기능 목록

- [ ] 로또 구입 금액을 입력받는다.
  - [ ] 입력 금액은 1,000원 단위여야 한다.
  - [ ] 1,000원으로 나누어 떨어지지 않을 경우 예외를 발생시킨다.
- [ ] 입력 금액에 해당하는 만큼 로또를 발행한다.
  - [ ] 로또 번호는 1부터 45 사이의 중복되지 않는 6개 숫자다.
  - [ ] 발행된 로또 번호는 오름차순으로 정렬하여 출력한다.
- [ ] 당첨 번호와 보너스 번호를 입력받는다.
  - [ ] 당첨 번호는 쉼표로 구분된 6개의 숫자다.
  - [ ] 당첨 번호와 보너스 번호는 1부터 45 사이의 숫자여야 한다.
  - [ ] 당첨 번호와 보너스 번호는 중복될 수 없다.
- [ ] 발행된 로또와 당첨 번호를 비교하여 당첨 내역을 계산한다.
- [ ] 당첨 통계 및 총 수익률을 계산하여 출력한다.
  - [ ] 수익률은 소수점 둘째 자리에서 반올림한다.
- [ ] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시키고, `[ERROR]`로 시작하는 메시지를 출력한 후 다시 입력받는다.
- [ ] MVC 패턴을 기반으로 기능들을 분리하여 구현한다.
- [ ] 각 기능에 대한 단위 테스트를 작성한다.
